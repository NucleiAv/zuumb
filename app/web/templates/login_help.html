Reset the dashboard password

This is a self-hosted single-user dashboard. Recovery is done from the deployment, not by email.

If you set a custom password in Settings and forgot it

  1. In .env, set DASHBOARD_PASSWORD_RESET=true.
  2. Restart the app (or the container). Startup wipes the custom credential and logs it.
  3. Sign in with the .env credentials (DASHBOARD_USER / DASHBOARD_PASSWORD, ships as admin / admin).
  4. Open Settings and set a new username and password.
  5. Set DASHBOARD_PASSWORD_RESET back to false.

If you only changed the .env password and forgot it

Edit DASHBOARD_PASSWORD in .env to a new value and restart. No reset flag needed while no custom credential is set.
