Reset the password

Self-hosted single-user dashboard. Recovery is done from the deployment, not by email.

Forgot a password you set in Settings

  1. Set DASHBOARD_PASSWORD_RESET=true in .env.
  2. Restart the app or the container. Startup wipes the custom credential.
  3. Sign in with the .env credentials (DASHBOARD_USER / DASHBOARD_PASSWORD, ships as admin / admin).
  4. Open Settings and set a new username and password.
  5. Set DASHBOARD_PASSWORD_RESET back to false.

Only changed the .env password

Edit DASHBOARD_PASSWORD in .env and restart. No reset flag needed while no custom credential is set.
